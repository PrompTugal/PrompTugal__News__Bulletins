    Every presenter here is a synthetic character built by code from characters.json. None is the likeness of a real person. They share one skeleton and one move set (moves.json), and this sequence is data too (choreography.json). Drag the scrub bar: any moment can be reached directly, because every frame is computed from the time alone.

    The voice in the lip-sync passage is version 1's synthetic voice, reading the bulletin's own checked sentences. The mouth shapes were made offline from it with Rhubarb Lip Sync.
